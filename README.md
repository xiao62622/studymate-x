# 学习通脚本 studymate-x 1.6.6

用于学习通、超星、智慧树等课程页面的播放控制、章节切换和题目辅助脚本。

## 使用说明

### 安装脚本

1. 在 Edge 或 Chrome 中安装 ScriptCat、Tampermonkey 或 Violentmonkey。
2. 打开本仓库的 `studymate.user.js`，点击 Raw，或复制文件全部内容到脚本管理器的新脚本中。
3. 保存脚本并刷新课程页面。脚本默认匹配超星、智慧树、polymas 和 neauce 域名，学校自建域名需要在脚本管理器中补充匹配规则。

### 播放与课程切换

1. 进入课程后打开脚本面板的「进度 → 播放与切换」。
2. 按需开启「自动播放」「播完下一节」和「末节后切换下一门」。首次使用课程切换前，先回课程列表导入课程。
3. 页面中的「播放 / 继续」「暂停」「下一节」和「下一门课程」可以手动控制当前任务。
4. 遇到浏览器禁止自动播放时，先在平台播放器中手动点一次播放。锁定章节、无法识别目录或平台提示需要处理时，自动切换会停下并显示原因。

### AI 答题

1. 在脚本面板的「AI API」中选择服务商，填写 API 地址、API Key 和模型后保存并测试连接。
2. 需要答题时打开「答题」，可单题解答，也可开启自动解答检测。截图问答支持截取题目、粘贴系统截图或上传不超过 3 MB 的 PNG、JPEG、WebP 图片。
3. API Key 只填写在脚本管理器的本地设置中，不要写入脚本文件、截图或提交到仓库。

### 本地预览与检查

打开 `preview.html` 可以体验本地播放器和章节切换，`demo.mp4` 是配套的 6 秒演示视频，不连接课程平台。运行 `npm test` 可执行浏览器自动化检查。

安装或更新：在 ScriptCat、Tampermonkey 或 Violentmonkey 中，用 `studymate.user.js` 的全部内容替换原脚本，保存后刷新课程页面。保留原脚本条目即可沿用旧版数据；新建一个重复条目可能导致两个浮窗同时出现。

在「进度 → 播放与切换」使用：

- **自动播放**：识别加载完成的视频或音频并开始播放。手动暂停后保持暂停，可点「播放 / 继续」恢复。
- **播完下一节**：当前视频自然结束后，先播放本页剩余视频，再打开下一任务页或下一章节。开启时同时开启自动播放。
- **末节后切换下一门**：在能确认目录末节时，按已导入课程的顺序进入下一门。开启时同时开启前两项；到末门后停止，不循环。
- **播放 / 继续、暂停、下一节、下一门课程**：手动控制当前播放器和课程页面。
- **停止自动**：关闭三个自动开关，取消待执行切换，并暂停当前播放器。

首次使用课程切换前，回平台课程列表导入课程。旧版只存了课程名称和编号，需要重新导入一次以补全课程入口。页面已有相同课程时会更新入口，不重复新增。课程卡片里的「打开课程」可以直接进入对应课程。记录用的课程下拉框仍用于本地归档。

自动开关会保存，刷新页面、切换章节或课程后继续生效。状态区显示播放、暂停、缓冲、结束和播放失败；已导入课程会保存最近一次播放状态、章节与时间。平台进度由播放器及平台原有页面操作正常更新。单个视频结束不会被当作整章或整门课程完成，也不会直接修改完成标记或提交进度接口。

已适配的目录包括超星 `.posCatalog_select`、课程主页 `.chapter_item`、智慧树 `li.video` 和 `.inner-li`。同源及跨域嵌套播放器需要相应帧内运行此脚本；脚本默认匹配超星、智慧树、polymas 和 neauce 域名。学校自建域名需要在脚本管理器中补充匹配规则。

遇到浏览器禁止自动播放，请在平台播放器中点一次播放。锁定章节、无法识别的目录、页面未响应和需要手动处理的平台提示会使自动切换停下，并显示原因。课程入口失效时回课程列表重新导入。作业、考试页面不执行自动播放和换章。

本地预览：打开 `preview.html`，其中的 `demo.mp4` 是 6 秒本地演示视频，可验证播放、暂停和章节切换，不连接平台。

验证：已用 Edge 的实际媒体播放和本地模拟课程页面进行浏览器检查，并在登录后的超星课程中实测了播放器识别、播放、暂停、继续、切换到本章测验、导入 14 门课程和打开下一门课程。详见 `实测记录.md`。1.2.1 补充了主页面直接读取同域多层播放器的兼容方式，帧内未运行脚本时仍可控制；跨域播放器继续使用消息桥。

如果个人空间的嵌套列表识别不到，可直接打开 https://mooc1.chaoxing.com/visit/interaction 后导入课程。

运行检查：安装 Node.js、Edge 和开发依赖后执行 `npm test`。也可用 `STUDYMATE_BROWSER` 指定 Chromium 浏览器路径，用 `STUDYMATE_PLAYWRIGHT_PATH` 指定现有的 `playwright-core`。

### 新增功能（1.4.2）
- 播放区默认使用 1×，支持 0.75×、1×、1.25×、1.5×、2×、3×、4×，不再提供 0.5×。
- 播放器可能在加载或播放过程中把倍速恢复为默认值；脚本会锁定所选倍速并持续校正，4× 在超星播放器中也能保持生效。
- 新增“AI API”页签，可配置豆包、OpenAI、DeepSeek、Claude、WorkBuddy 和自定义 OpenAI 兼容服务商，支持保存 API 地址、Key、模型、温度和最大输出 Token，并可测试连接。
- AI API 请求优先使用脚本管理器的跨域通道，避免课程网页的 CORS 限制导致“连接失败”；首次使用自定义服务商时，请在脚本管理器弹出的跨域权限提示中允许对应域名。
- 豆包、OpenAI、DeepSeek、WorkBuddy 使用 OpenAI 兼容格式，Claude 使用 Anthropic Messages 格式。

### 答题（1.5.0）

- 在「AI API」保存服务商、API 地址、Key 和模型，随后打开「答题」。答题面板列出当前页面识别到的题目。可单题解答，也可开启「自动解答检测到的题目」，让模型依次处理。同一章节内可复用已有解答。答案和解释显示在浮窗中。
- 在「截图问答」点「截取题目」，允许 Edge 捕获当前课程选项卡，拖动框选并点「使用选区」。也可把系统截图粘贴到问题框，或上传 3 MB 以内的 PNG、JPEG、WebP。点「询问 AI」会发送预览中的图片和你输入的问题。图片输入取决于所选模型，需在「AI API」配置支持图片的模型。
- 超星章节测验支持嵌套页面和自定义题目字体。脚本管理器安装时会下载字体解析库和字形表。含图题与无法读取文字的题目可使用截图问答。
- 1.5.1 支持超星视频播放过程中弹出的题目。开启自动解答后，播放器弹题出现时会读取题干与选项，结果显示在「答题」面板。
- 1.6.0 在「答题」中新增「自动填充并提交答案」，适用于可读取表单的超星章节测验和视频弹题，支持单选、多选、判断和可编辑的文本答案。开启后可手动点「解答此题」，也可同时开启「自动解答检测到的题目」。整组答案已填入后，脚本会点击平台的提交按钮。遇到图片题、无法匹配的模型答案或未识别的表单时，在面板查看状态并手动处理。开关设置会随脚本保存。
- 1.6.1 适配 `mooc-ans/work/doHomeWorkNew` 中的超星 `before-after` 选项和页面提交函数。模型返回 `答案：A`、`答案：对` 等常见文本时也会尝试填入，整卷完成后调用平台确认提交流程。
- 1.6.3 在「答题」中新增「定时提交」，默认关闭。开启「自动填充并提交答案」后，默认在整组答案填好时立即提交。需要延迟时，可先打开「定时提交」，设置「填充后等待（秒）」（默认 30 秒）。章节测验和视频弹题都会在整组答案填好后显示倒计时，归零后提交。等待中修改秒数会从原填充时刻重新计算剩余时间；关闭「定时提交」会立即提交，关闭「自动填充并提交答案」会取消倒计时。
- 1.6.4 页面答题收到空答复或空答案数组时，等待 5 秒后重试该题。开启「自动填充并提交答案」并开始答题后，脚本会检查同组选择题和每个填空，补答漏题，并重新填入被清空的答案。整组通过复查后才会提交，平台要求最终确认时会再次检查。截图问答收到空答复也会重试，可点击「取消重试」。
- 1.6.5 开启「自动解答检测到的题目」后会同时启用整组自动提交。AI 完成整组题目并提交确认后，脚本会自动打开目录中的下一节。题目位于嵌套页面时由课程顶层页面执行切换。
- 1.6.6 开始答题前会检查当前章节测验的完成状态。页面显示已提交、已完成或待批阅时，不再重复请求 AI，直接进入目录下一节。
